# LiteraMK-AI – Source List

## 1. Dataset Sources

The project uses a collection of Macedonian literary works consisting of:

- 128 literary text files in TXT format.
- An Excel metadata file named `Naslovi_knigi_tabela .xls`, containing 134 records.

Following preprocessing and validation, 123 literary works were included in the final dataset.

The exact original dataset source and its licensing conditions require further verification.

The original and processed literary texts are excluded from the public GitHub repository until redistribution rights are confirmed.
